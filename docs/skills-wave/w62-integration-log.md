## 4. 八处冲突怎么解

### 4.1 `js/issues.js`:取 `theirs` 的结构,但 W54 落的三件事要逐条数回来

`w59` 的四处冲突块合起来就是"UMD 头 + 表驱动 + UI 段移出"这一整套重构,结构面**必须取 `theirs`**
(否则等于不合)。风险全在**它的重构基线不含 W54**:W54 往 `js/issues.js` 落了三件事,
逐条查它们并入后在哪里:

| W54 落的东西 | 并入后在哪 | 机械取 `theirs` 会怎样 |
|---|---|---|
| `no-review` 未审中危 | **自动合并区**(冲突块 3 之前的 `if (st.reviewStale) … else if (…)`) | 保住 |
| `review-stale` 判旧中危 | 同上 | 保住 |
| `shot-stable-lexicon` SK-19 稳定词低危 | **冲突块 2 的 `ours` 侧**(`LEX` 词表 + `lexLine`)与**冲突块 3 的 `ours` 侧**(取值点) | **整条消失** |

第三条是本槽唯一需要"往对侧的新结构里补东西"的地方:`theirs` 的投影表只有 6 行,没有稳定词那一面
(它分叉时那一面还没接进问题中心)。补法不是把 `ours` 的手写取值点粘回去——那会在表外多出第二处
`Skills.check` 调用点,当场撞上 `w59` 自己加的「只此一处取值点」断言;正确的补法是**按表的口径补一行**:

```
{ kind: 'shot-stable-lexicon', sev: 'low', stage: 'shots', skill: 'shots.promptEightDim', level: 'episode', phase: 'post',
  name: '提示词稳定词/用词提醒', line: lexLine, cap: 4,
  tail: '——判的是该镜真实发出去的那条提示词,判据取自知识库条目,只提醒不拦生成' },
```

四个字段逐个对着 `ours` 的手写块反推:`name` 取自它 `label` 里除掉「「集名」N 处」之后那半
(表的 `labelOf` 自己拼前半)、`line` 取 `lexLine`(冲突块 2 已按并集留下)、`cap: 4` 与 `tail`
取自它的 `detail` 拼法。**行序排在 `shot-size-linkage` 之后、`caption-unreadable` 之前**:
两条同挂 `shots` 面,表的整面缓存(`cache[r.stage]`)保证"一次跑完按条目分挂"这件 W54 定的形态不退回;
`sort` 只按 `sev` 排且 V8 的 `sort` 稳定,故同为低危的四条在输出里仍是 `ours` 原来的相对次序。

**这一处的等价性是实测出来的**,不是推出来的:把并入前(`4967ae9`)的 `js/issues.js` 与合入后的投影核
放进两个 `vm` 沙箱,喂同一份摊开了四种稳定词形态(写全 / 只写一面 / 模糊词 / 一个都没写)
外加景别成串与超长台词的夹具,`online` 两种取值下逐字节对跑:

```
online=false | 并入前 5 条 / 合入后 5 条 | 逐字节相同
  kinds: stale-shots,script-craft,shot-size-linkage,shot-stable-lexicon,caption-unreadable
online=true  | 并入前 5 条 / 合入后 5 条 | 逐字节相同
```

夹具里 `shot-stable-lexicon` 真的出条目(不是"两侧同为空"的假对照)。

冲突块 1 的聚合清单同样是**`ours` 是 `theirs` 的超集**:`theirs` 写
「失败镜/过期镜/未分镜/缺剧本/低分审片/待确认/成片过期/主体缺图/跨镜主体不一致/字幕读不顺」,
`ours` 另有「未审片/审片记录过期/提示词稳定词」三项与 `Domain.episodeState(blockers/counts/审片三态)`
那个括注,故注释正文取 `ours`、模块包裹取 `theirs`。

弹窗顶部提示语
  分叉时:全项目待处理问题聚合(失败/过期/未分镜/低分/待确认/缺图,与流程条同一套状态推导)
  主  干:全项目待处理问题聚合(失败/过期/未分镜/未审/低分/待确认/缺图,与流程条同一套状态推导)

目录索引表(#7):`ours` 侧带 `w56`/`w57`/`w60` 三行、`theirs` 侧带 `w59` 一行,机械取任一侧都会丢行。

`theirs` 侧在那一行后面还多带一个空行,`ours` 侧的表与 `## 一分钟摘要` 之间没有空行,取 `ours` 的形态。
