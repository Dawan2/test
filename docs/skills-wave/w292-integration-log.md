## 六、残留(按明令一条没代修,原话逐条保留)

   一行分镜都不渲,故不是"漏挂"而是"没地方挂"——但从这两档进来的人读到「要改 2 行」之后,
   想知道是哪几行仍得先切到另一档或点开弹窗。要收得给那两档补一处按行的落点
