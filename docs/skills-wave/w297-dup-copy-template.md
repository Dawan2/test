## 一、收的是哪一条

两侧逐位/逐行卡片小标、项目详情面那几枚与项目列表那几枚铺完了。**功能面是齐的,欠的是这句话本身:**

(撞了几处、代价是什么、去哪儿收拾)。十句各写一份的代价是:改一句代价的说法要挨着改十处,

本槽只收这一格:**这句话收成 Domain UMD 一份模板,页面只注入单位词、引用面、收拾入口与数。**

它们是**用户真会去按的那两个按钮**,而说明句里那道预览 + 确认闸的承诺
(先看计划、确认才改、一位/一行不删、零积分)与另八句逐字同一套。

还难读,故落地是三种形态共用一张单位词对照表(§3)。

## 三、模板长什么样:一张对照表 + 一句闸 + 三种形态

全在 `js/domain.js`(UMD,段内不碰 `window`)。

### 3.1 `Domain.DUP_UNITS`:单位词一换,连带换掉的是四件事

清点时量出来的关键一件:**单位词不是一个字的替换**。换掉「位 → 行」时跟着换的还有四件:

| 对照表键 | 位(主体侧) | 行(镜头侧) | 它在句子里管哪一段 |
|---|---|---|---|
| `thing` | 主体 | 镜头 | 数的是什么(角标上「🧹 主体 id 重复 N 位」那两个字) |
| `first` | 首位 | 首行 | 跨单位那一枚里「按 id 只取得到首位/首行」 |
| `take` | 只找得到首位 | 只取得到首行 | 报总数那一句里的代价前半 |
| `lookup` | 按 id 取主体 | 按 id 取镜的地方 | 小标里「按 id 取…只找得到第 1 位/行」 |
| `batch` | 批量补图 | 批量生成 | 哪个批量动作逐个计费(代价后半) |
| `intact` | 名字与设定 | 画面与提示词 | 改 id 时哪些内容一个字不动 |

调用方**只注入单位词本身**,这六段一律按表取。单位词不在表里时一个字都不编(回 `{label:'', title:''}`,
角标跟着整个不露、不抛)——渲染那一层拿到什么都得渲得出来。

### 3.2 `Domain.dupGateNote(unit)`:那道闸怎么说,七处逐字同一句

`先看计划,确认才改 id,一{位|行}不删、零积分`。七处现取它(`episodes.js` 3 / `projects.js` 2 /
`roles.js` 1 / `storyboard.js` 1);逐位小标那一档说的是短一句「先看计划,确认才改」(收在模板里),
跨单位那一枚要把两侧的"不删"合成一句(「一位不删、一行不删,零积分」),这两档有意不经它。

### 3.3 `Domain.dupCopy(o)`:三种形态,各回 `{ label, title }`

| 形态 | 用在哪几句 | 调用方注入 | 模板负责 |
|---|---|---|---|
| `mark` | #1 #2(逐位/逐行小标) | `mark`(`Domain.dupIdMarks` 的一格)、`scope` 引用面、`scopeNote`、`entry` 收拾入口 | 「第几位/共几位」那几个字、首处留原 id 还是改发新 id、代价那一句、闸那半句 |
| `count` | #3–#9(报总数那七枚) | `n` 数、`scope` 引用面、`eps` 摊在几集、`list` 逐集清单、`cta` 收拾入口那一段、`marks` 位、`short` 位 | 角标上那几个字、代价那一句(取 `take`/`batch`)、有清单就改说"共有"并把清单缀在代价之后 |
| `rollup` | #10(项目列表页头,跨单位) | `unit` 收成数组、`total`/`n`、`list`、`scopeNote`、`cta` | 「N 个项目有重复 id」、两侧 `thing`/`first`/`batch` 按数组逐个摊开 |

两个开关值得单说,它们各对应清点里量到的一处真差别:

- **`marks`**——「撞车的每一位卡片上另有一枚小标」这半句**只有真挂了小标的那两面能说**
  (#5 详情面主体那枚点过去落到「主体」页,那一屏逐位挂着小标;#7 分集卡片那枚点进本集工作区,
  那一屏逐行挂着小标)。#6 详情面镜头那枚多集时落到「分集」**列表**,那一屏挂的是卡片角标而不是逐行小标,
  故它有意不给这一位——判据两向都钉着(§5 那两格新断言)。
- **`short`**——#7 分集卡片本就在这一集上,角标上不必再重复「镜头」二字(收编前那句正是
  `🧹 id 重复 N 行` 而不是 `🧹 镜头 id 重复 N 行`)。这一位就是为了让"收编不改一个字"成立。

### 3.4 转义归页面那一层

模板回**纯文本**(它不认识 DOM),`U.esc` 仍留在十处渲染点上。理由是两条:
`Domain` 是 UMD、CLI 与服务端也 `require` 它,`U` 在那两端不存在;而 id、项目名、集名都是用户数据,
在渲染处整句转义一次比在模板里逐段转义少一份"哪段转过哪段没转"的账
(收编前 `js/projects.js` 那两句是逐个字段转的,收编后整句转一次,渲出来逐字节相同)。

## 四、收编不改一个字:十句逐字与收编前相同

**这不是"顺手改口径"的槽。** 十句渲出来的可见串与 `title` 与收编前逐字节相同,判据里逐句写着期望值
(§5 那条模板断言把主体侧/镜头侧那两句完整期望值抄成字面,收编时改了一个字当场失配)。
外观也一个像素没动:`tag yellow`、`sb-views` 那三条内联样式(`margin-top:3px;font-size:10px;padding:1px 7px`)、
`data-x`/`data-epdup`/`data-dupsubj`/`data-dupshot` 那几个挂点、`cursor:pointer`
与三处 `stopPropagation` 一律原样。
