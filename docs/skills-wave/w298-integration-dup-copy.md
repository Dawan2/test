   收文案单源那条网只有整跑或点名 `domain` 段时才张开。要补是给那条判据加一句所属登记
   (或让页面那几段也引它一次),本槽按明令不代修。
10. **"十句同读一份表"在用例层没有直接判据,只有源级点名 + 本槽这一格 live。**
   §二那几手源级变异咬的是"页面上还写不写得出那几段字面",而"页面拿到的值真是从
   `DUP_UNITS` 那张表现取的"这一句,用例层现在靠的是模板自己那几条(`domain` 段)加
   逐文件调用点计数——中间"页面 → 模板"那一跳没有用例。本槽用 live 探针在运行期换表补上了
   这一格(§3.2 十格),但它是探针不是判据,跑完就没了。要补是加一条"把 `DUP_UNITS` 换掉后
   四屏渲出来的十句全跟着换"的浏览器沙箱用例,本槽按明令不代修。

## 八、这一槽可复用的两件事

1. **快进形槽第十九次,取证怎么摆已经定型,但这一槽换来一格新的。** `diff` 空集与 `tree` 相等
   一律只当形状记录;"新变异锚点在 P1 上全部失配"当正面证据用。**新的那一格是:
   当对侧改的是"同一句话收成一份"这类纯收编时,渲出来的东西前后逐字节相同(§3.3 现取 diff 空),
   于是行为面探针也说不出话**——这时要换的不是判据"类别",而是**探针本身要动手改一处再看**:
   把单源那张表在运行期换掉一格,看十个消费点跟不跟着换。跟着换才是"单源真在生效",
   而不是"渲得出来"。
2. **给源级单源设变异时,按判据宿主选套件,别按被改文件所属那一层选。** M8/M9 头一遍打在
   `commands` 上两手全绿,只因那条源级判据挂在 `domainTests` 上。按后者选出来的绿是
   "判据没跑到"而不是"判据接不住",拿它当漏网报出去会把一条真在场的网记成缺口。
