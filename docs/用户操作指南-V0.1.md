# 【虎鲸漫剧】用户操作指南-V0.1

版本：V0.1
适用对象：AI 短/漫剧工作室、MCN 机构、品牌方、个人创作者等
最后更新：2026 年 08 月 19 日

# 一、简介

虎鲸漫剧：AI 短漫剧全流程智能创作平台
Slogan：讲好每一个故事！

我们致力于解决传统短/漫剧制作中"门槛高、流程碎、一致性差、效率低"的核心痛点。平台已全量接入真实模型服务（LLM 剧本理解、火山引擎文生图/文生视频、豆包语音 TTS 配音、FFmpeg 本地视频处理），从"剧本 → 主体 → 分集 → 分镜 → 生成 → 成片"全流程一站式完成。

🔧 核心痛点与解决方案

痛点 1：流程割裂（手搓多个工具）→ 方案：一站式全流程，一个账号搞定所有环节。
痛点 2：主体崩坏（多集长相不一）→ 方案：资产化管理，AI 自动提取并锁定角色/场景/道具，多集一致。
痛点 3：抽卡率高（浪费大量资源）→ 方案：分镜脚本先行、提示词人工审核点、智能审片三维评分，先把文字磨对再生成，降低返工。
痛点 4：频繁等待（分镜间需等待）→ 方案：批量生成 + 一键跑批多集连跑；所有耗时 AI 解析都收纳进右侧"导演助手"Agent 对话栏，等待期间可继续操作其他页面。

✅ 为什么选择虎鲸漫剧？

💰 门槛低：每个页面顶部都有"学习引导层"，告诉你当前在干什么、下一步该点哪里，新人无需培训即可上手。
🎬 AI 导演级理解：内置"本集理解"（剧情脉络/情绪曲线/节奏规划/视觉基调/悬念设计），不懂分镜也能拍。
🤖 导演助手贯穿全程：右侧 Agent 对话栏贯穿剧本→主体→分集→分镜→生成→成片全流程，自然语言即可让它改剧本、改主体、改分镜，修改前给预览、可一键应用、可撤销。
⚡ 工业化量产：分镜表/节拍板/一键跑批三种模式，支持多集无人值守连跑（生成→审片→合成流水线，断点续跑）。
🎓 专家雇佣：平台预置多位不同风格的 AI 导演 Agent（系统提示词+提示词模板封装），一键雇佣即切换整套创作风格。

# 二、快速上手

## 步骤 1：注册与登录

访问平台（本地部署 http://localhost:8000），注册账号。账号分两种：

个人账号：日常创作全部功能可用。
公司主体：额外拥有"团队管理"（多项目组、成员邀请、积分分配、消耗统计）。

注册成功即赠送 100 积分。

## 步骤 2：新建项目

左侧栏点"项目管理"→ 右上角"新建项目"：填写项目名称、描述，选择创建方式（工作流/画布）、项目类型与风格（漫剧/动漫/写实，支持自定义风格），可上传封面。

工作流模式：按"剧本→主体→分集→分镜→生成→成片"流水线推进，适合整部剧制作。
画布模式：自由节点式创作，适合灵感编排与单点实验。两种模式可随时互切（画布页左上角模式徽标 ⇄，工作流项目页"🎨 画布"按钮），内容互保留。

## 步骤 3：积分与计费

平台按实际消耗计费：分镜生成、文生图、视频生成、配音、审片等按次扣积分；创作失败自动退费（积分记录可追溯）。个人中心可查看实时余额与流水。

# 三、工作流模式（主流程）

项目页顶部有一条"创作主线"步骤条：剧本 → 主体 → 分集 → 分镜 → 生成 → 成片，每步可点击直达；分镜工作台顶部还有"上一步/下一步"引导按钮。

## 3.1 上传剧本与 AI 围读

在项目页"剧本"区上传整部剧本（支持超长文本）或直接编写。AI 解析产出：基础信息、一句话卖点、故事梗概、人物小传、章纲、集纲、每集正文。
解析在右侧"导演助手"对话栏中流式进行，不阻塞页面操作。
每次剧本围读会留存二级记录，可随时回看历史解析版本。

## 3.2 主体提取与生成（人物/场景/道具）

AI 从剧本提取全部主体（人物/场景/物品）的描述与绘画提示词。
人工审核点：生成图片前可逐一修改提示词，确认后再点"生成"，避免直接抽卡。
人物形象生成白底图（半身+三视图），列表小图显示半身，点开可查看/编辑完整三视图。
主体图不合格可重新生成或本地上传替换；确认后"保存主体"入库。

## 3.3 分集管理

剧本拆集后进入分集列表：每集显示标题、场次摘要、涉及人物/场景/道具、镜数。
可新建分集、调整顺序、编辑每集内容；"内容"视图按 集 → 场次 → 剧情/情绪节拍 层级折叠展开，方便同层级预览。

## 3.4 分镜工作台（核心页面）

进入某集后，顶部为三种模式 tab：分镜表 / 🥁 节拍板 / 🏭 一键跑批。

学习引导层（顶部常驻横栏）：
左侧告诉你"当前在哪一层、该干什么"（随状态动态变化）；
中间显示当前状态（镜数、已出片数、续接状态、整集均分）；
右侧概要本剧导演风格设定（项目风格、已雇佣专家、导演设定摘要）。

分镜脚本层（文字层）：
点步骤条"分镜"或"⋯ 更多 → 分镜脚本"进入。按「场次 → 剧情 → 情绪节拍 → 文字分镜」四级组织，支持按层级折叠/展开（只看场次/展开到节拍/全部展开）。
"✨ AI 拆解场次与节拍"出初稿 → 人工编辑 → "🧠 拆解为文字分镜" → 确认无误点"✅ 确认为分镜表"。

分镜表层（镜头层）：
中栏：视频播放器 + 缩略图时间轴（生成中的分镜有状态可视；失败会标注原因，如提示词违禁被模型拒绝，便于修改后重新发起）；时间轴支持多分镜连播（一段播完自动播下一段）。
右栏（编辑/素材/声音三个页签）：剧情、运镜（🎥 机位库）、提示词编辑；"⊙ 一键审片""🗂 历史版本"为文字按钮，其余提示词辅助功能（大屏编辑/＠引用资产/⌖智能识别/⭐收藏/🕘历史/🧰润色）收在"🛠 提示词工具 ▾"下拉里。
＠引用资产：提示词中用 @主体名 引用角色/场景/道具，自动关联其参考图（含人物音色参考），生成视频时模型可识别参考主体。
历史版本：每镜每次生成/修片都留版本，可对比（双视频同一时间轴同步播放、同步拖动）与一键回滚。
生成策略：分镜参考（默认）/ 首尾帧（可继承上一镜尾帧、跨集续接）/ 多图融合。
更多入口："⋯ 更多"菜单含整集审片、分镜脚本、快速编辑、镜头组、分镜序列、导演设定、本集理解、参数配置、导入分镜（本地/资产库/CSV）、批量处理（定为终稿/选帧入库/智能超清/字幕擦除/一键审片，进入点选模式逐镜选择）。

## 3.5 生成视频与合成成片

顶部"🎬 生成视频 ▾"：批量生成视频 / 批量生成音频（TTS 配音）/ 批量合成音视频。
"🎞 合成成片"：把本集各分镜视频按顺序合成整集（自动混配 TTS 音轨）。"▶ 预览长视频"可从头连看。
生成失败自动退费，时间轴上会标注失败原因。

## 3.6 三种量产模式

分镜表：逐镜精修，默认模式。
🥁 节拍板：5 段式节拍驱动量产，一块节拍板 = 一次长段落生成（≤10s），适合快速出粗片。
🏭 一键跑批：多集流水线无人值守连跑（批量生成 → 智能审片 → 合成成片），逐条扣费、失败退费、断点续跑；审片不达标超限的集标"待人工"。

## 3.7 导出与交付

成片后可"导出 ⬇"：直接下载成片，或打包剪映草稿（含真实视频素材），导入剪映继续精剪。
更多导出下拉支持多种格式；成片库中每集成片可在线播放预览、可全屏。

# 四、画布模式

新建项目时选择"画布"，或在文本节点中随时与工作流互切。
创建文本节点：上传/编写剧本 → 开始创作 → 画布上生成人物/场景/物品分组，逐组生成主体图。
创建图片/视频节点：上传素材或写提示词，@引用素材，拖拽节点右侧"+"派生图生图/图生视频/合成长视频等节点。
画布工具：左下角小地图、智能对齐、适配视图、缩放；框选节点可打组/解组/创建副本/删除。
切回工作流：点左上角"项目名 · 画布模式 ⇄"徽标确认即可，画布内容保留。

# 五、资产库

统一管理跨项目资产：创建主体（上传/从项目保存）、新建分组、共享分组协作。
分镜里"选帧入库"可把任意镜头关键帧存为资产，供其他项目复用。

# 六、百宝箱

集中放置单点工具：视频剪辑（裁剪/分割/拼接，FFmpeg 真实处理）、视频编辑（人物/背景替换）、视频超清（分辨率提升，档位真实区分）、视频去字幕（对白/全局擦除）、关键帧提取等。分镜右栏"⋯ 更多工具"可带当前镜头素材一键跳转预填。

# 七、团队管理（公司主体）

多项目组：可新建多个项目组，各自独立邀请码、成员名单与消耗统计，分开管理不同剧集团队。
成员管理：负责人分享邀请码（MV-XXXXXX），成员"凭邀请码加入"；可移除成员、刷新邀请码。
积分分配：管理员可直接为成员划拨积分。
人员消耗统计：按成员/时间/粒度（日/周/月）筛选，自动汇总总消耗积分、视频生成次数、任务数、人均消耗，附趋势图与成员排行，数据来自成员真实流水。

# 八、偏好学习

⚙ 全局配置：自填迭代系统提示词与 skill——文生图/文生视频/审片三套提示词模板（支持 {style}/{subject}/{shot} 变量）、默认模型、默认音色、默认画质比例、导演设定五维（光影/色调/情感氛围/服化道审美/表演气质）。
🎬 专家雇佣：平台预置多位风格化 AI 导演 Agent（冷峻悬疑/甜宠轻喜/热血燃系/治愈日常/电影感写实）。雇佣后：① 该导演的设定五维注入所有生成提示词；② 三套提示词模板替换为专家版本；③ 导演助手切换为该专家人设与你协作。可随时解雇恢复默认。

# 九、个人中心

入口在左侧栏左下角用户卡（头像 + 用户名 + 实时积分数，整块可点）。
💎 积分管理：积分中心（7 档充值 + 自定义金额，3000 元以上档位有额外赠送；也支持兑换码）、积分记录（每笔消耗/获得/退费可追溯）、充值查询（订单号/金额/渠道/时间）。
🔌 API 设置：默认走后端代理（免 Key）；高级用户可切"自定义直连"，填入自有 OpenAI 兼容接口的 Base URL 与 Key，使用自己的模型算力。
账号设置：页头可修改密码。

# 十、常见问题

Q：提示"本地存储空间已满"？
A：浏览器 localStorage 有容量上限，大量占位图/素材会占满。请保持后端运行并登录账号——数据会同步到服务端，本地写满不阻断使用，仅提示一次。

Q：生成失败扣了积分？
A：不会。所有创作类操作失败自动退费，积分记录里可查到"refund"流水。

Q：导演助手没反应？
A：请确认后端已启动且已登录（代理模式需登录）；偶发的上游空响应平台已自动重试。持续异常可到 个人中心 → API 设置 切换自定义直连。

Q：生图/生视频用的什么模型？
A：火山引擎 doubao-seedream（文生图）/ doubao-seedance（文生视频），文本模型可在个人中心查看与切换。
