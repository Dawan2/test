## 七、这一槽可复用的两件事

- **快进形槽连到第五条时,"空 diff"这一格已经彻底不作证了,而变异台在纯注释槽上也大半失效——
  这时唯一还说得出话的是锚点台,而它必须成对地立:产出面的锚点要在 P1 上失配、在合完那侧命中;

  再配一手 M7 那样的"整槽退回"变异:它全绿这件事本身,就是这张锚点台为什么非有不可的读数。
- **给注释类改动设 live 探针时,把量出来的读数与同一次运行打出来的那句注释原文摆同屏**
  (照抄 §2.3:P1 那一侧 `ok=4 landed=4` / 四行各得一段片,与紧挨着的「写回的还是首行」同屏)。

  前者是本槽收的病,后者不成立,混着讲会把结论讲歪。
