## 八、这一槽可复用的一件事

**快进形槽里,"跑起来全绿"是最弱的一层并集判据,得从树上取。**
M-REV 那一手把整槽退回后 **720/720 全绿**,而 `git diff M-REV P1` 同时是空集:
树上没有任何一条判据说得出"这里本该多一条用例"。棘轮只在"删一半"时响,
故合入槽的并集非得从**不随删除一起消失的东西**上取——根树 oid 对不对得上对侧、
用例名多重集双向对减干不干净、索引行少没少。
**判据的对象是那棵树,不是那次运行。**

**同一个取数口上每多一条命令,变异的红条数就得跟着加一格,而"加了几格"只有两边各跑一遍才说得出。**
M1(摘 `findSubject` 的按名兜底)在我方尖上红 1、合完红 2:红条数从 1 变 2 这件事本身就是并集的读数。
只在合完那棵树上跑一遍变异,红 2 说明"有人接着",却说不出"这一槽接上了第几条";
两边各跑一遍,差额才是**净新增的看守面**。合入槽的变异台一律成对跑,单边那份读数是残的。
