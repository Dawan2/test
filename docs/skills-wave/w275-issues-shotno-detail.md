## 一、这一处坏在哪

问题中心的失败镜条目与过期镜条目,明细里印的是「镜头 2:上游超时」「镜头 2、3、4 生成后输入有变化」。

坏账落在两处对不上:

1. **与分集页对不上**。人照着问题清单上的号回分集页找镜,而分集页的缩略图墙、分镜面各弹窗页头
   (W271 收的)、审片面(W269/W267 收的)、生成面后台审片面板(W273 收的)现在**全按实位出号**。

W274 §六 4 把这一面记成残留时留了一句「口径要单独定:进的是 `detail` 文案,与命令回执同源、编排层也读」。
本槽定的就是这一句:`detail` 是**投影出来的展示文案**,不是落库文本——`Issues.collect` 每次现算,
不写库、不进任务中心、不进积分流水;CLI `issues` / MCP `hujing_issues` 把它原样吐出来给人和助手读,
读的仍是"给人看的那个号"。故它归展示持久族,与前三面同判词收。**落库文本那一族本槽一处未碰。**
