## 3. 收紧成什么

改动落在 `tests/unit.js` 同一处,14 行入 2 行出,`releaseTests` 条数不变。

```js
const aggAt = rel.indexOf('/* G4 过期镜'), aggEnd = rel.indexOf('/* G7 合规命中');
assert(aggAt > 0 && aggEnd > aggAt, 'G4–G6 那段聚合取不到(段头挪窝或改写就同轮改本条,别把它留成恒真)');
const aggCode = rel.slice(aggAt, aggEnd).split('\n').filter(t => t.trim() && !/^\s*(\/\/|\/?\*)/.test(t));
assert(aggCode.length > 10, 'G4–G6 那段的可执行行取不到(整段被判成注释本条就成恒真),实测 ' + aggCode.length + ' 行');
assert(aggCode.some(t => /Domain\.episodeState\(/.test(t)), …);
assert(aggCode.some(t => /agg\[[^\]]+\]\s*\+=[^;]*\bcounts\b/.test(t)), …);
```

三处口径是有意选的:

- **「可执行行」按行首形态判**,与同文件 W162 那条源级判据同一写法(整行注释与空行豁免,
  不做"先剥注释再扫"——过度剥离是漏判)。**这一格是承重墙**:退回成整段扫之后,
  产品退回 + 补一句讲历史的行注释就能重新变绿(4.M5′/M5″ 是这一格的对照实测)。
- **锚点取不到即红**(第 1、2 格)。缺了这两格,把那段挪走或改名就让整条静默变绿——
  正是本槽在收的那类毛病,不许换个形状再犯一次。
- **`Domain.episodeState(` 带括号**。段内另有一行 `!Domain.episodeState` 是"模块加载了没"的探测,
  不是取数;不带括号会把探测行也算成落点,那样第 3 格就拦不住"探测照旧、取数换掉"(4.M3′ 反证)。

`js/release.js` 一个字节未动,交付包打包行为、`storyboardFailed` 回报、落地失败抛错三面全未碰。

## 6. 残留与欠账

1. **收紧后的这条仍是源级判据,钉的是"那段代码长什么样",不是"那三个数从哪儿来"。**
   它拦得住 4. 里那几种退回,拦不住"`Domain.episodeState` 自己把 `counts` 算错"或
   "另有一处旁路先把 `agg` 填了再走这段"。**真正的行为面判据仍然没有**——
   最接近的是「聚合缺 Domain」那条(钉 `Domain` 不在时三门 warn)与「聚合半途抛错」那条
   (钉抛错时不拿半截数),两条都不验**counts 的值有没有原样流到门禁回执上**。
   写它要一条新用例:桩掉 `episodeState` 让它回一组与就地数镜头**必然不同**的 `counts`,
   再点 G4/G5/G6 的 `info` 与 `fix.shotIds`。本槽任务口径是"收紧那一句",故未新立用例,如实登记。
2. **第 4 格的正则认的是 `agg[…] += … counts …` 这个形状。** 把累加拆成两行
   (先 `const n = st.counts[k];` 再 `agg[k] += n;`)会让它红,而那是个合法重写——
   即这一格有**误判方向**(要求写法保持单行累加),与 W162 残留 3 记的
   「行内注释会被扫」同类:**判据强加给写法的约束,不是零成本的**。
   处置方向是把两格并成一句"段内 `counts` 的取数与 `agg` 的加数之间有数据流",
   而那要在零依赖约束下自己写词法/数据流分析,本槽没做。
