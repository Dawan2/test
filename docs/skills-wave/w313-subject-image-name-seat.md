## 八、这一槽可复用的一件事

**"按名解析"与"按名写回"是两件事,判据要分开量。**
本条 ① 起手写的是"回执报的名字对不对",而变异 C(认完人再按 id 回到首位)**照样绿**:
回执 `name` 取自解析到的那一位,图却写在首位——**回执说对了,库里换了人**。
把判据换成"四位逐位对图"的那一整串之后 C 当场红。
凡是"解析一位、再往它身上写"的命令,回执面与落库面必须各量一次:
**回执是解析的产物,证不出写回落在哪一位。**

**"这一路是现跑语义、不是缺陷"的那一格,恰恰是新判据的量尺。**
按 id 点名落第 1 位这件事本槽一个字不改,但它必须**同轮进判据**:
没有 ② 那一格,把取数改成"永远取最后一位"时 ① 照样绿(点名的 C 恰好也不是首位)。
**要证"够得着点到那一位",就得同时钉住"别的点名方式落在哪"**——
一格判据只说得出"落到了 C",两格连读才说得出"落到 C 是因为点了 C"。
