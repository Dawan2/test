### 2.1 第一次合并(W183)怎么并的 —— 本槽的主要冲突

`tests/unit.js` 只给了**一个**冲突块,而它横跨的正是这两支相撞的那一段:
我方那一侧是 W149 那条转发形态用例的尾巴 + **W181 五条判据全文**,对侧是 W183 源级那条判据的函数体。

先把撞车说清楚。W183 摘掉的是这一段:

```js
try {
  if (window.Bus) Bus.on('*', (ev) => { … Bus.emit('release.dirty', …); });
} catch (_) {}
```

而 W181 的五条判据里,有四条的判定对象就在这段里:

| W181 判据 | 它钉的对象 | 转发摘掉之后 |
|---|---|---|
| T1 那处 `catch` 只兜注册这一下 | `js/release.js` 恰 **1** 处空 `catch`、`try` 块顶层恰 **1** 句且那句是 `Bus.on('*'` | 对象没了(空 `catch` 现取 0 处) |
| T2 `catch` 兜不兜住十门逐字不变 | 两形态门禁签名相等 **+** `release.dirty` 订阅者的隔离计数 | 前半仍成立,后半的 `release.dirty` 不再有人发 |
| T3 走得到那处 `catch` 的形态在成品页不存在 | `Bus` 单处整体赋值、装载序、**通配订阅四家名单** | 名单从四家变三家 |
| T4 headless 侧没有同一张网 | `js/release-core.js` | **一字不受影响** |
| T5 转发件的全部代价 | 一条主线事件占 2 格、40 条后真事件剩 25 | 对象没了 |

**任务口径两处话在这一格上是不相容的**:「删转发 / 不要把转发加回去」与「W181 五条判据仍须绿」不能同时按字面满足。
落地取前者,理由有三,逐条可复核:

1. 任务口径对 W183 那一条**两次点名**要删,纪律段那句「保留 …W181 空 catch…、W183 删掉 dirty 转发」在同一句里并列,
   而 W181 对 `js/release.js` 的产品贡献本就是**零 diff**——它的结论是「**别去填**那处 `catch`,填掉等于拿十项门换一个走不到的形态」。
   W183 走的不是"填掉"那条路:它把 `catch` 兜的**那句注册本身**摘了,于是"注册失手"这个形态从根上不存在。
   W181 那条结论在合完的树上落得更硬,不是被推翻。
2. 反事实实测:W181 五条**原样**放在合完的产品码上 **红 4**(C1)。"两侧都留着不动"不是一个存在的选项。
3. **W181 自己写了怎么办**。三条判据的注释里各留了一句同轮重算的口径,逐字如下:
   T1「改写形状就同轮改本条,别把它留成恒真」、T3「名单变了就同轮重掂量那处 `catch` 的下游」、
   T5「转发若被摘掉或有人加命名订阅者,**同轮在这里重算**,别让它悄悄漂」。

据此并集:**五条判据一条不删、各钉的那一面一面不丢**,判定对象按新实况换:

| # | 合并后的判据 | 怎么换的 | 原样保留的部分 |
|---|---|---|---|
| T1 | `那处 catch 连同它兜的那句注册一起摘了(源级:零空 catch、装载期零 Bus.on;行为:半截 Bus 也导得出整支)` | 源级从「恰 1 处空 `catch` 且 `try` 顶层恰 1 句注册」改判「零空 `catch` **且装载期零 `Bus.on(`**」(注释整段抹掉后扫,故讲历史那段注释原样留着);另加一句 `window.Bus` 仍是本模块依赖,不许把整条依赖也当顺手删掉 | 行为面**逐字未动**:`no-on` 形态下 `Release` 仍是对象、七个出口全在、十项门一门不少 |

### 5.5 README 冲突的并集怎么证的

主 `README.md` 那句「单元测试(N 项断言…」是一整行几万字,三次合并每次都给一个冲突块。
本槽的手法是**先证超集再做外科**:把两侧按 `;(?=\*\*)` 切成段做多重集比对,打印"只在我方"与"只在对侧"的段。
三次读数:

| 合并 | 我方段数 | 对侧段数 | 只在我方 | 只在对侧 |
|---|---|---|---|---|
| 1(W183) | 19 | 16 | 5(含首段数字差) | **2**:首段数字差 + `**Bus 事件留痕不被转发件对折**` |
| 2(W184) | 19 | 17 | 6 | **4**:首段 + `**Bus 通配订阅**`(旧段,不取)+ 两段因锚点位移而整段不等,真独有的是 `**显式子集里的过期镜两端各有行为面**` |
| 3(W186) | 19 | 17 | 5 | 同形,真独有的是 `**断点条「重生成过期镜」印的是这一按真下发引擎的镜数**` |

三次都证出**我方是超集**(对侧独有的只有它自己新加那一段),故取我方整句再把对侧那一段按锚点插回。
**没有用过 `--ours`,也没有 `git checkout <old> -- .`**:摘冲突标记那一步是逐块指定行号做的,
且每一次都先把对侧全文吐到临时文件、再逐段核对独有内容有没有落下。
