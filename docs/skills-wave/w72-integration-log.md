## 2. 基线怎么选的

```
git rev-parse origin/cursor/w67-integration-a5c1   # cbb2b24

git merge-base --is-ancestor cbb2b24 1e4627c && echo YES   # YES
```

远端 `w70` 前缀命中且 `w67` HEAD 是它的祖先,故走第 1 条:基线 = **`1e4627c`**。
