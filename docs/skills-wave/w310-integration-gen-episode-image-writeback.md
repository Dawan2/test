## 八、这一槽可复用的一件事

**判"合进来了"这句话的分量,看的是锚点台有没有成对立,不是 `git diff` 是不是空的。**
本槽 M-REV 那一手把 W309 整槽退回仍 **718/718 全绿**——三方份数自洽地一起变小、棘轮 `>=` 照旧成立,
树上一条不响。同一刻 `git diff M P2` 也是空集。两个"看起来没事"叠在一起,
唯一能分开"整槽还在"与"整槽没了"的,就是产出面那 21 条在 P1 上**一条都不命中**、在 M 上**条条命中**。

**只加测的对侧,产品面两个方向都零 diff,这本身要当成一条判据去证而不是默认。**
本槽 X-GRAFT 那一手(M 的测试树移到 P1 的产品树上跑,719/719 全绿)与产品面 `git diff` 空集互为两面:
前者证"新判据不依赖任何产品改动",后者证"确实一处产品代码都没改"。
少了前者,"零 diff"只说明文件没变,说不出那条新用例到底在守什么。
